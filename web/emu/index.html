FM‑23 Guide (buttons · pages · gestures)
  • All parameter pages work the same: SELECT moves the cursor · ALGORITHM edits it · KNOB 1–4 edit the visible rows (names, not numbers)
  • HOME: transport, INSTRUMENT row / ALGO encoder = keyboard instrument (DRUMS → BASS → LEAD), tempo/swing/master, drum pads + bass/lead strip
  • SEQ: pattern matrix · keys toggle steps · REC+key cycles velocity · LANE 6 = chain editor · AUTO = per-step automation
  • EDIT cycles the SOUND tabs: BASS → LEAD → DRUMS → LAYER — ENGINE (voice name), filters/drive/level, PORTA, ARCH, VOICE, ANALOG
  • Engines: BASS 0 classic / 1 B01 / 2 B02 / 3 B03 / 4 B04 acid (default) · LEAD 0 classic / 1 L01 / 2 L02 / 3 L05 / 4 L07 / 5 L03 / 6 L04 / 7 L06 scream (default)
  • INSTRUMENT (HOME): 0 DRUMS · 1 BASS · 2 LEAD — the whole keyboard plays the one instrument, no splits
  • VOICE (LEAD tab): 0 RETRIG / 1 LEGATO / 2 UNISON · ANALOG (LAYER): per-voice drift · PORTA: glide · ARCH: SINGLE/DUAL/STACK
  • ENV / LFO open the MOD page for the voice selected in SOUND: ATTACK/RELEASE/DECAY/PITCH and ON/RATE/DEPTH/SHAPE
  • ARP: ON, STYLE, HOLD (drone), OCTAVE · FX: DELAY, REVERB, DRIVE, TYPE · GLO: ROOT, SCALE, MIDI CLK
  • GEN (SCL): SEED / SCALE / STYLE / MODE — twist to generate; tap any pad to GENERATE now; MODE=1 builds the 8-cell song chain
  • PLAY start/stop · REC = loop pedal anywhere except SEQ (record → stop+loop → clear) · SAVE saves the current page's data
  • TD‑3 lanes: SLIDE (glide, cross-pattern) and GATE (note length) travel with patterns
  • OCT− + OCT+ held 5 s = recovery (UBOOT) — never used for anything else
