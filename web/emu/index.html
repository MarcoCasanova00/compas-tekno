Compás TEKNO Guide (buttons · pages · keyboard)
  • The 14 panel buttons are: OCT− · OCT+ · MIX · ACC · BASS · PERC · EDIT · SET · HOME · SAVE · FILL · SEC · PLAY · RACK
  • PLAY starts/stops the groove (keyboard Space does the same). FILL fires a fill, SEC jumps past the section, ACC toggles accent emphasis.
  • HOME = main groove screen. Knobs: KNOB 1 = BPM (60–180) · KNOB 2 = feel/swing · KNOB 3 = bass level · KNOB 4 = overlay level · MODE = energy (BASE/LIFT/BREAK) · SONG = browse songs.
  • BASS: OCT± = root note up/down · KNOB 1 = cut · KNOB 2 = bite · KNOB 3 = level · KNOB 4 = style (classic/acid). PERC: OCT± = clave direction · KNOB 1–4 = overlay levels.
  • MIX: keys 1–6 mute, 7–12 solo · SPEED knob (varispeed) · LEVEL knob.
  • EDIT: step editor for the current part — keys 1–16 toggle steps, OCT± switches bar 1/2.
  • RACK = rack/sequencer: the SONG knob cycles the 30 grooves (presets 0–29 — at the last one the wheel clamps, turn it back); SEC toggles pattern editing (KNOB 1 picks one of the 15 bank sounds, keys toggle 16 steps, KNOB 2 = BPM, KNOB 3 = hit strength, KNOB 4 = level, OCT± = bar); FILL toggles roll; MIX toggles the FX layer; RACK again records into the sequence.
  • SET: song slots (16). OCT± / SONG knob browse · SEC cues the slot · SAVE saves it (stop playback first — the firmware refuses to save while playing) · KNOB 3 = repeats/phrases · KNOB 2 = BPM · KNOB 4 = count-in · keys 1–16 cue a slot.
  • Keyboard (27 pads): the pads trigger the groove's instruments; the note row also triggers parts (INTRO/VERSE/VARIATION/CHORUS/BREAK/END) and nearby keys layer overlays — the LEDs show which are live.
  • MASTER slider = volume (0–150%, default 100). The current groove is TRIBAL TEKNO (155 BPM, four-on-floor, offbeat hats) — switch grooves on the RACK page.
